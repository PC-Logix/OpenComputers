# Third-party notices

OpenComputers contains or distributes work from other projects. Their license
texts are retained in the [`LICENSES`](LICENSES) directory and are packaged in
release JARs under `META-INF/licenses`.

| Component | Use | License file |
| --- | --- | --- |
| JNLua | Lua runtime bindings and native libraries | [JNLua](LICENSES/JNLua.txt) |
| LuaJ | Pure-Java Lua fallback | [LuaJ](LICENSES/LuaJ.txt) |
| Typesafe Config | Configuration parser | [Typesafe Config](LICENSES/Typesafe-Config.txt) |
| OpenScreens | Adapted display assets and implementation portions | [OpenScreens](LICENSES/OpenScreens.txt) |
| GNU Unifont | Glyph data used by screens and manuals | [GNU Unifont](LICENSES/Unifont.txt) |
| wcwidth tables | Unicode character-width data | [wcwidth](LICENSES/wcwidth.txt) |
| Computronics | In-tree content assets and content definitions ported from Computronics | [Computronics](LICENSES/Computronics.txt) |

Optional mod integrations are compiled against their respective APIs but are
not bundled into the OpenComputers JAR. Those projects remain subject to their
own licenses.
